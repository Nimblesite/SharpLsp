# 上下文菜单

SharpLsp 的大多数上下文菜单命令都位于 VS Code 解决方案资源管理器中。扩展目前不会在“问题”面板中添加上下文菜单。

## 解决方案资源管理器

| 节点 | 可用操作 |
|---|---|
| 解决方案 | 构建、重新构建、清理、移除未使用的包、统一包版本、复制名称 |
| 项目 | 打开项目文件、构建、重新构建、清理、浏览 NuGet 包、移除未使用的包、复制名称 |
| 依赖项文件夹 | 添加项目引用、添加 NuGet 包 |
| NuGet 包 | 移除包 |
| 项目引用 | 移除项目引用 |
| 类型符号（C#） | 排序成员、在资源管理器中显示、复制完全限定名称、复制名称 |
| 其他源码符号 | 在资源管理器中显示、复制完全限定名称、复制名称 |

### 构建、重新构建和清理

这些命令以所选解决方案或项目为目标：

- **构建：** `dotnet build <target>`
- **重新构建：** `dotnet build <target> --no-incremental`
- **清理：** `dotnet clean <target>`

构建输出显示在终端中；解析出的编译器错误和警告会添加到 VS Code 诊断。

### 打开项目文件

在编辑器中打开所选 `.csproj` 或 `.fsproj` 文件。

### 添加项目引用

此操作显示在项目的依赖项文件夹节点上。它会显示其他已发现项目的快速选择列表，然后编辑项目引用。

### NuGet 操作

**浏览 NuGet 包**会打开以所选项目为目标的 [NuGet 包管理器](/zh/docs/nuget/)。依赖项和包节点还会在适用时提供添加、移除、未使用包清理和版本统一工作流。

### 符号操作

- **复制完全限定名称**会复制源码符号的完全限定名称。
- **复制名称**会复制短名称；项目和解决方案节点也支持此操作。
- **在资源管理器中显示**会定位到符号的源文件。
- **排序成员**适用于 C# 类、结构体、接口、枚举和记录节点。它遵循配置的可访问性、类别和字母顺序层级，而不是始终只按名称排序。

## 编辑器菜单

对于 C# 和 F# 编辑器，SharpLsp 会添加 **Debug Program**。代码操作、重命名、导航和其他语言功能使用 VS Code 的标准 LSP 菜单和命令，而不是 SharpLsp 专用的上下文菜单项。
