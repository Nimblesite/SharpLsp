# SharpLsp チュートリアル

SharpLsp は VS Code の中で使い方を教えます。チュートリアルはステップごとに短い映像を再生し、その間にあなたは自分のエディターと自分のコードでそのステップを実行します。SharpLsp がその操作に応答するとステップが自動で完了し、次の映像が始まります。「完了にする」ボタンはありません。何も返さないホバーは数えられません。

最初が F#、次が C# です。どちらの言語にも同じ 7 つのステップがあります。

{% video "vscode-tutorial" %}

## チュートリアルを開く

- **初回起動時。** SharpLsp を初めて起動すると、VS Code の「はじめに」ページで F# のウォークスルーが開き、その横にチュートリアル パネルが表示されます。
- **いつでも。** コマンド パレット（Cmd+Shift+P、Windows と Linux では Ctrl+Shift+P）から **SharpLsp: チュートリアルを開く** を実行します。
- **「はじめに」ページ。** **ヘルプ → ようこそ** を開き、**F# で SharpLsp を学ぶ** または **C# で SharpLsp を学ぶ** を選びます。

パネルには F# と C# の切り替え、その言語の 7 つのステップ、現在のステップの映像があります。**Open one for me** を押すと、読み込まれたソリューションのソース ファイルが開くので、以降のすべてのステップで SharpLsp が応答できます。

## ステップ

映像の各ステップ（F# が先）です。時刻を選ぶとそのステップから再生します。

{% chapters "vscode-tutorial" %}

| ステップ | 操作 | 完了する条件 |
|------|-----|---------------|
| ファイルを開く | F# または C# のソース ファイルを開く | その言語のエディターがアクティブになる |
| ホバー | 関数、型、値の上にマウスを置く | SharpLsp がクイック情報を返す |
| コード補完 | 値の後にドットを入力するか、Ctrl+Space を押す | SharpLsp が補完候補を 1 つ以上返す |
| 定義へ移動 | シンボルにカーソルを置いて F12 を押す | SharpLsp が定義を見つける |
| すべての参照を検索 | シンボルにカーソルを置いて Shift+F12 を押す | SharpLsp が参照を 1 つ以上見つける |
| コードの修正 | 警告またはエラーの上で Cmd+.（Windows と Linux では Ctrl+.）を押す | SharpLsp がコードアクションを 1 つ以上提示する |
| ソリューション エクスプローラー | アクティビティ バーの SharpLsp アイコンを選ぶ | ソリューション エクスプローラーが開く（両方の言語で完了） |

パネルは各ステップに対応するドキュメントの映像を再生します：[ホバー](/ja/docs/hover/)、[コード補完](/ja/docs/completions/)、[定義へ移動](/ja/docs/go-to-definition/)、[リファクタリングのレッスン](/ja/docs/refactoring/)。

## 設定

- `sharplsp.tutorial.showOnStartup`（既定値 `true`）：`false` にすると、初回起動時にチュートリアルが開かなくなります。
- **SharpLsp: チュートリアルの進捗をリセット** はすべての完了を消去するので、チュートリアルをやり直せます。

チュートリアルは、`code serve-web` で自分のマシンから配信するブラウザー版 VS Code でも動作します。vscode.dev と github.dev にはローカルの拡張機能ホストがないため、SharpLsp を実行できません。
