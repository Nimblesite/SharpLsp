# Security and regression review for v0.32.1

Reviewed on 2026-11-09 against v0.32.0. Implements [DIST-CI-AUDIT], [DIST-RUNTIME-ACQUIRE] and [RAZOR-ARCHITECTURE-GENERATOR].

## Findings and changes

- SDK 10.0.303 includes runtime 10.0.11 and remains within feature band 300 under `latestPatch`. Updated the repository, container, reusable actions and workflows to SDK 10.0.403, which includes runtime 10.0.14. This includes the Brotli out-of-bounds write fix and the completed SocketAsyncEventArgs security fix. The downloaded local SDK was verified against Microsoft's published SHA-512 before extraction. [Microsoft release notes](https://github.com/dotnet/core/blob/main/release-notes/10.0/10.0.14/10.0.14.md)
- Updated bundled Roslyn compiler, Features, Workspaces and MSBuild packages together from 5.6.0 to 5.9.0. Read the installed SDK's compiler assembly version independently and retained the existing exact SDK/compiler regression guard. The newer Razor generator omits ObjectPool and supplies name spans for MVC elements. Updated the generator file inventory and classify MVC elements through their compiler descriptors so prefixed tags keep binding and hovering correctly.
- Updated the Blazor WebAssembly fixture and DevServer from 10.0.11 to 10.0.14. Microsoft's Blazor debugger fix requires updating DevServer package references. [Microsoft guidance](https://github.com/dotnet/core/blob/main/release-notes/10.0/10.0.14/10.0.14.md)
- Node 20 reached end of life on 2026-04-30. Updated CI, publishing, Pages and the development container to supported Node 24 LTS, and changed the installed-module cache key to keep artifacts scoped to that runtime. [Node release schedule](https://github.com/nodejs/Release/blob/main/schedule.json)
- Gradle 9.8.2 already contains the published Gradle security fixes. Verified the committed wrapper JAR against Gradle's official SHA-256 and added the official distribution ZIP checksum to the wrapper properties. [Gradle release notes](https://docs.gradle.org/9.8.2/release-notes.html)
- The latest fetched Dependabot head `890242b95a3e956948110a336edc8e3bbf91c831` is already an ancestor of this branch. Compatible Node types, vsce and ESLint updates are retained. Proposed sysinfo 0.40, TypeScript 7, languageclient 11 and typescript-eslint 8.72 upgrades were previously rejected after compilation, peer dependency or lint failures. The retained versions have no findings in the current package scans.
