What's new in C# 14, step by step in VS Code: extension members, the field keyword and null-conditional assignment, on .NET 10 LTS. If you know the C# 13 features, these are the three you will use first. Every frame is the real VS Code running SharpLsp, a free, open-source alternative to C# Dev Kit, on a real .NET 10 SDK project. No Visual Studio 2026, no JetBrains Rider licence.

1. C# 14 extension members: open an extension block for any type and put properties in it, not just methods.
2. Use it on any string: completion offers the IsBlank property beside the built-in members, and hover shows exactly where it is declared.
3. Go to definition: F12 lands straight on the extension block.
4. The field keyword: give a setter a body with no backing field to declare. field is the one the compiler makes for you.
5. Null-conditional assignment: ?. works on the left of an equals sign, too. If the object is null, the assignment just doesn't happen.
