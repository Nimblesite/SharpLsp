What this C# in VS Code tutorial covers, in F# and then in C#:
1. Open a C# or F# file in VS Code: Cmd+P on macOS, Ctrl+P on Windows and Linux.
2. Hover: see a symbol's type, signature and documentation.
3. C# IntelliSense code completion: type a dot to list only what fits.
4. Go to definition: F12.
5. Find all references: Shift+F12, across the whole solution.
6. Quick fix (code action): Cmd+. on macOS, Ctrl+. on Windows and Linux. This fixes a warning or generates a missing method.
7. Solution Explorer for VS Code: the solution, its projects and their files.
